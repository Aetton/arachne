# Компоненты

Компонент — группа сценариев на главной странице. Он хранится в базе и отвечает за
название секции, иконку и порядок. Исполняемого YAML-фрагмента внутри компонента нет.

| Поле | Смысл |
|---|---|
| `slug` | стабильный ключ и значение `scenario.component` |
| `label` | название группы на dashboard |
| `icon` | CSS-класс Tabler Icons, например `ti-server` |
| `sort_order` | порядок групп; затем сортировка идёт по названию |

Компонент можно создать или изменить в **Admin → Scenarios → Components**. Slug
существующего компонента через эту форму не переименовывается: он приходит скрытым
полем и служит первичным ключом.

Удалить компонент можно только тогда, когда на него не ссылается ни один сценарий.
Иначе сервер вернёт `409 Conflict` и количество мешающих сценариев.

У команд тоже есть список `components`, но текущая проверка доступа не выдаёт права
автоматически на основании этого списка. Доступ дают возможности роли и ACL сценария.
Список компонентов команды сейчас остаётся описанием области ответственности и
заделом для дальнейшей фильтрации.
