# Работа оператора

Операторский интерфейс состоит из трёх частей: список сценариев, список запусков
и рабочая область. Всё остальное — детали паутины под полом.

## Вход

Откройте портал и войдите локальной учётной записью. Сессия хранится в cookie
`arachne_session`: она недоступна JavaScript, действует семь дней по умолчанию и
проверяется при каждом защищённом запросе.

Если учётная запись выключена администратором, уже выданная сессия перестанет
работать при следующем запросе.

## Поиск и выбор сценария

Сценарии слева сгруппированы по компонентам. Поиск смотрит на slug и название
сценария, а также slug и название компонента. Состояние раскрытых групп сохраняется
в браузере.

Если сценария не видно, причина почти всегда одна из трёх:

- он выключен или не имеет опубликованной версии;
- у вашей роли нет `scenarios.view`;
- ACL сценария не разрешает вам просмотр.

## Форма запуска

Нажмите на сценарий. Arachne построит форму из `params` опубликованной версии.

| Тип | Как выглядит | Что уходит в запуск |
|---|---|---|
| `string` | текстовое поле | строка |
| `boolean` | флаг | `true` или `false` |
| `choice` | обычный список | выбранная строка |
| `select` | список; для веток — поиск | выбранная строка |
| неизвестный тип | текстовое поле | строка |

Динамический список веток загружается из Forgejo при открытии формы. Если API
недоступен, поле блокируется и под ним показывается настоящая ошибка, а не
ритуальное «что-то пошло не так».

## Запуск и живые логи

После нажатия **Spin thread** создаётся UUID запуска и открывается его карточка.
Логи приходят через Server-Sent Events примерно каждые `0,4` секунды.

В карточке есть:

- параметры запуска;
- общий статус: `running`, `success`, `failed` или `cancelled`;
- шаги и паук каждого шага;
- группы Ansible `PLAY`, `TASK`, `RUNNING HANDLER`, `PLAY RECAP`;
- поиск по логу, перенос строк, автопрокрутка и копирование;
- артефакты шага и общий список ссылок после успешного запуска.

Строка из `stderr`, `fatal:`, `failed:`, `ARACHNE ERROR`, `PORTAL ERROR` или
структурная ошибка помечают группу как упавшую.

## История

Список запусков обновляется каждые три секунды и показывает не больше 15 последних
записей. Обычный пользователь видит свои запуски, администратор — общие.

Завершённый запуск читается из базы. Он сохраняет параметры, статус, время,
структурированные логи, артефакты, ID версии и снимок определения сценария.

## Отмена

Кнопка **Cancel run** отправляет сигнал отмены всем шагам сценария. Реально отменится
только активный шаг, если его паук умеет резать свою нить:

- `forgejo` вызывает endpoint отмены Actions run;
- `ansible-local` посылает процессу `SIGTERM`;
- остальные встроенные пауки пока не реализуют полноценную отмену.

Отмена best-effort: успешный ответ интерфейса означает, что сигнал отправлен, а не
что внешний исполнитель уже гарантированно остановился.

## Артефакты

Arachne не проксирует содержимое артефактов. Она хранит метаданные и показывает
ссылку, которую вернул исполнитель или удалось извлечь из лога. Доступ по этой
ссылке всё ещё определяется Forgejo, Nexus или другим хранилищем.
