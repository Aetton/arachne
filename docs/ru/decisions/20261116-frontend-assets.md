# Скрипты и стили редактора и Secrets вне шаблонов

Дата: 16 ноября 2026.

## Контекст

Крупные CSS и JavaScript блоки в base, форме сценария и Secrets затрудняли
навигацию, проверку синтаксиса и тестирование. Справка DSL уже использовала
общий каталог, но скрытый внутри шаблона completion Monaco сохранял отдельный
список пауков и типов.

## Решение

Вынести базовые стили и тему в `base.css` и `theme.js`. Стили формы сценария
хранить в `scenario-form.css`, worker setup — в `monaco-environment.js`,
инициализацию Monaco, completion, lint и сохранение — в `scenario-editor.js`.
Панели редактора остаются в существующем `scenario-editor-ui.js`.

Secrets использует `secrets.css` и `secrets.js`. Оба исходных CSS слоя объединены
в прежнем порядке. Точки подключения ресурсов и порядок CSS/JS сохранены;
скрипты подключаются без async/defer, обработчики inline HTML сохраняют глобальные
имена функций. В шаблоне редактора остаётся только JSON с серверными данными.

`scenario-dsl-catalog.js` хранит один live-каталог для completion, lint и справки.
Обновление API меняет этот каталог; при ошибке сохраняется начальный снимок.
Completion учитывает обычные строки YAML-списков `- type:`.

## Последствия

Новые JS-файлы автоматически попадают в синтаксические проверки scripts/check.py.
Сборщик приложения и новый UI-фреймворк не требуются. CDN-зависимости сохранены.
Дальнейшая консолидация CSS overrides — отдельная задача с визуальной проверкой.
