# Единая сборка документации

Дата: 16 ноября 2026.

## Контекст

GitHub Pages собирал Fumadocs из `docs-site`, а Dockerfile продолжал собирать
VitePress из `docs`. Документация внутри Арахны и на Pages имела разную навигацию.

## Решение

Markdown хранится в `docs/`, единственный сборщик — Fumadocs в `docs-site/`.
Dockerfile экспортирует справочник с `DOCS_BASE_PATH=/wiki` в `/app/wiki/`.
GitHub Pages использует `/arachne`. Префикс запросов поиска выводится из той же
переменной. Зависимости фиксируются в package-lock и устанавливаются через npm ci.
Старые URL `/wiki/ru/...` сохраняются статическими редиректами.

## Последствия

Node требуется только при сборке, FastAPI продолжает раздавать статические файлы.
Изменение DOCS_BASE_PATH требует пересборки. VitePress и его конфигурация удалены.
Оба префикса проверяются отдельными CI-сборками.
