# Границы ядра и интеграций

Дата: 16 ноября 2026.

## Контекст

В core находились OpenTofu runtime, работа с Git-кешем playbook repository и
описания конкретных пауков для редактора. Реестр плагинов применял credentials
из хранилища приложения, а Brood-нормализатор сам читал Golden Images.

## Решение

Перенести tofu, tofu_state и playbook_repository в `api/integrations/`.
Каталог справки перенести из core в `api/editor_metadata.py`; единственный
источник описаний из предыдущего ADR сохраняется. Ядро больше не импортирует
хранилища credentials, Golden Images или подключений.

Применение credentials выполняет `run_engine.init()` перед импортом пауков.
Приложение передаёт оркестратору `brood_credentials_resolver`; нормализатор
вызывает его только для legacy artifact без явного credentials_ref. Реализация
lookup находится в integrations и сохраняет прежний best-effort fallback.

## Последствия

URL, subjects шины, параметры исполнителей и расположение runtime state
сохраняются. Внутренние Python import paths изменены; собственным расширениям,
импортировавшим эти helpers из core, нужно обновить импорты. Совместимые wrappers
в core не оставлены, чтобы не возвращать обратную зависимость.

При прямом использовании нормализатора вне приложения lookup defaults теперь
нужно передавать явно. Готовые Brood targets и явные credentials_ref имеют прежний
приоритет. Это разделение модулей в одном процессе, а не выделение новых сервисов.

Решение уточняет расположение каталога из
[ADR о справке редактора](20261116-shared-editor-contracts.md).
