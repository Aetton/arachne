# Единый каталог контрактов редактора DSL

Дата: 16 ноября 2026.

## Контекст

Контракты пауков существовали независимо в core, HTTP endpoint и браузерном
fallback. Поля и действия расходились; fallback мог показывать неустановленные
плагины после ошибки загрузки API.

## Решение

`api/core/editor_metadata.py` хранит единственный каталог описаний и строит
метаданные по реестру установленных пауков и триггеров. Вызывающий код передаёт
профили Golden Images; core не обращается к HTTP или БД. Ответ не разделяет
изменяемые структуры с исходными контрактами.

HTTP endpoint и обработчики формы используют одну функцию. Форма передаёт
начальный снимок через JSON script с Jinja tojson. Справка, hover и completion
используют этот снимок до обновления через API и сохраняют его при сетевой ошибке.
Отдельный каталог пауков в JavaScript удалён.

## Последствия

Контракт редактируется в одном месте; изменение начального снимка требует
перезагрузки формы. Дополнительные пауки без описанного контракта получают
минимальную справку из своего FAMILY. Это каталог помощи редактора, а не новая
валидация DSL или ограничение поддерживаемых исполнителями legacy actions.

Полнота общей документации и эксплуатационных инструкций отслеживается отдельно:
[техдолг #149](https://github.com/Aetton/arachne/issues/149).
