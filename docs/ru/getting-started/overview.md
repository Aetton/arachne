# Обзор

Arachne работает как общий пульт для Forgejo, Ansible и OpenTofu. Она хранит
сценарии, строит форму запуска, вызывает шаги по порядку и собирает результат.

Обычный запуск выглядит так:

1. пользователь выбирает доступный ему сценарий;
2. Arachne собирает параметры формы и создаёт запись запуска;
3. оркестратор идёт по шагам сверху вниз;
4. каждый шаг передаётся своему пауку;
5. логи летят в интерфейс, а артефакты попадают в контекст следующих шагов;
6. первый провал или отмена останавливает оставшиеся шаги;
7. итог, логи, параметры и ссылки на артефакты сохраняются в базе.

## Основные понятия

- **Сценарий** — опубликованное и версионируемое описание формы, триггеров и шагов.
- **Компонент** — группа сценариев в интерфейсе: название секции, иконка и порядок.
- **Шаг** — одна операция одного паука. Шаги пока выполняются строго последовательно.
- **Паук** — адаптер к исполнителю: Forgejo Actions, локальному Ansible, OpenTofu
  или другому сценарию Arachne.
- **Нить** — выполнение одного шага через шину.
- **Триггер** — способ начать сценарий: вручную, по cron или после другого сценария.
- **Артефакт** — унифицированный результат шага: пакет, архив, Actions artifact,
  виртуальная машина или любой объект с метаданными.
- **Запуск** — конкретное выполнение сценария. Оно хранит снимок версии, поэтому
  последующее редактирование сценария историю не переписывает.
- **Шина** — транспорт между оркестратором и исполнителями. В одном процессе это
  память, для разнесённой схемы предусмотрен NATS.
