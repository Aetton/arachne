# Журнал запусков

Полный журнал доступен по адресу `/journal` из верхнего меню и компактной
истории на дашборде. Каждый запуск открывается отдельной страницей с логом.

- Фильтр «Кто запускал» выбирает инициатора запуска, независимо от автора сценария.
- Доступны фильтры сценария, группы/подгруппы и статуса, поиск по названию,
  slug сценария или ID запуска.
- По умолчанию выбранная группа включает все подгруппы. Режим «Только выбранная
  группа» исключает вложенные группы.
- Сортировка: время, пользователь, сценарий, группа, статус; оба направления.
- Пагинация: 25, 50 или 100 строк. Параметры сохраняются в URL.
- Время отображается в UTC, что указано в заголовках таблицы.

Администратор видит все запуски. Остальные пользователи видят только свои,
включая доступные значения фильтров; ссылка на чужой запуск не даёт доступа.

Название и группа сценария берутся из сохранённого снимка запуска. Для старых
запусков без снимка используется текущий сценарий. Подписи групп и иерархия
подгрупп соответствуют текущему дереву. Имя пользователя берётся из его текущего
профиля. Запуски без пользователя помечаются как системные.
